# PRD: 文件自动同步管理器 v1

## 问题陈述

个人用户在日常工作中频繁产生文件（文档、设计稿、代码等），需要手动打开百度网盘客户端或网页进行上传备份。这个过程繁琐、容易遗忘，缺乏自动化的文件备份手段。用户需要一个"设置一次、自动运行"的工具，将本地文件实时备份到云端，无需改变既有工作习惯。

## 解决方案

一款基于 Electron 的桌面端文件自动同步工具。用户只需：
1. 授权绑定百度网盘账号
2. 拖拽文件到应用窗口即触发上传，或注册需要监听的文件夹
3. 文件发生变更时自动上传到云端备份
4. 随时浏览云端文件列表并手动下载

应用最小化后驻留系统托盘后台运行，静默完成同步工作。

## 用户故事

### 百度网盘授权
1. 作为一个用户，我想要通过 OAuth 授权绑定我的百度网盘账号，以便应用能代理我进行文件上传和下载操作。
2. 作为一个用户，我想要应用自动刷新过期的 Token，以便我不需要反复登录授权。
3. 作为一个用户，我想要在授权失效时收到通知并方便地重新授权，以便同步功能不会静默中断。

### 拖拽上传
4. 作为一个用户，我想要将文件直接拖拽到应用窗口的指定区域，以便快速上传到云端备份，文件保留在原路径不产生副本。
5. 作为一个用户，我想要看到正在上传的文件名称、进度百分比、传输速度和预估剩余时间，以便了解上传进展。
6. 作为一个用户，我想要同时拖拽多个文件或文件夹，以便它们依次排队上传。

### 传输队列
7. 作为一个用户，我想要所有上传和下载任务在一个统一的队列中管理，以便我有清晰的全局视图。
8. 作为一个用户，我想要暂停、恢复或取消队列中的某个任务，以便我能灵活控制传输顺序。
9. 作为一个用户，我想要网络中断后任务自动重试，以便我无需手动重新发起上传。
10. 作为一个用户，我想要在退出应用时有未完成任务时收到提醒，以便我不会意外丢失传输进度。

### 文件监听自动同步
11. 作为一个用户，我想要注册任意本地文件夹为监听源，以便该文件夹内的文件变更自动上传到云端。
12. 作为一个用户，我想要监听源的变更事件有一个短暂的防抖延迟，以便短时间内多次保存不会触发重复上传。
13. 作为一个用户，我想要在监听文件夹不可访问时收到通知，以便我能及时处理路径变更问题。
14. 作为一个用户，我想要本地文件被删除时云端文件不受影响，以便作为纯备份用途不会误删云端数据。

### 云端文件浏览与下载
15. 作为一个用户，我想要浏览百度网盘指定目录下我的文件列表，以便了解云端有哪些文件。
16. 作为一个用户，我想要看到云端文件的名称、大小和最后修改时间，以便我能快速定位需要的文件。
17. 作为一个用户，我想要从云端文件列表中选择文件下载到本地，以便我能取回之前备份的文件。
18. 作为一个用户，我想要下载时同样看到进度展示，以便了解下载进展。

### 冲突处理
19. 作为一个用户，我想要在上传时如果云端版本比本地版本更新时收到明确提示，以便我不会意外覆盖更重要的版本。
20. 作为一个用户，我想要在冲突时有三个选择：保留本地版本、保留云端版本、保留两份，以便我能根据不同场景做出合适的决定。

### 文件过滤
21. 作为一个用户，我想要在设置中配置排除规则，以便某些文件或文件夹不会被自动同步。
22. 作为一个用户，我想要使用通配符配置排除规则，以便我能灵活匹配文件模式。

### 系统托盘与后台
23. 作为一个用户，我想要关闭窗口时应用最小化到系统托盘而非退出，以便同步任务能持续在后台运行。
24. 作为一个用户，我想要通过托盘图标快速查看同步状态和执行常用操作，以便我无需每次都打开主窗口。
25. 作为一个用户，我想要在设置中开启或关闭开机自动启动，以便我能根据自己的需要控制后台运行行为。

### 通知
26. 作为一个用户，我想要在传输完成、发生冲突或错误时收到桌面通知，以便我能及时了解同步状态。
27. 作为一个用户，我想要在设置中选择通知级别（全部通知 / 仅错误和冲突 / 关闭），以便我能控制通知的打扰程度。

### 主题与外观
28. 作为一个用户，我想要在深色和浅色主题之间切换，以便我能选择适合自己使用习惯和环境的视觉风格。

### 传输历史
29. 作为一个用户，我想要查看最近的传输记录（文件名、方向、状态、时间），以便我能追溯同步活动。

## 实现决策

### 技术栈
- **框架**: Electron + React + TypeScript
- **构建**: Vite + electron-builder（打包 Windows NSIS 安装包）
- **UI 样式**: CSS Variables 实现深浅主题切换
- **文件监听**: chokidar（Node.js 最成熟的文件监听库）
- **本地存储**: electron-store（加密存储配置和 Token）+ better-sqlite3（传输记录）
- **开机自启**: electron-auto-launch
- **网盘 API**: 百度网盘 Open API（RESTful，OAuth 2.0 授权）

### 模块架构

**主进程模块（Electron Main Process）：**

| 模块 | 职责 |
|------|------|
| AuthManager | OAuth 授权流程、Token 存储与自动刷新、授权状态管理 |
| TransferQueue | 上传/下载任务队列（并发上限 3），失败重试（最多 3 次，指数退避 1s/2s/4s），进度回调每 100ms 推送，队列持久化（SQLite） |
| FileWatcher | 基于 chokidar 监听注册文件夹，防抖 300ms 聚合变更，过滤规则检查后触发同步 |
| SyncEngine | 同步协调中心：接收拖拽/监听事件，调度冲突检测，协调传输队列 |
| CloudAdapter | ICloudAdapter 接口定义 + 百度网盘适配器实现（upload/download/listFiles/deleteFile/getFileInfo/getQuota） |
| ConflictDetector | 上传前比较本地/云端文件修改时间，判定是否冲突，触发用户选择流程 |
| FilterManager | 维护排除规则列表（支持精确匹配和通配符），提供匹配检查接口 |
| TrayManager | 系统托盘图标与右键菜单（打开/暂停/最近传输/设置/退出），桌面通知（三档可选），开机自启开关 |
| ConfigStore | 基于 electron-store 的应用配置读写（加密存储） |

**渲染进程模块（React）：**

| 模块 | 职责 |
|------|------|
| AppShell | 主窗口布局框架、导航栏、主题切换 |
| DropZone | 拖拽接收区域，文件拖放检测与上传触发 |
| TransferPanel | 传输任务列表视图，实时进度条，状态标签，暂停/取消操作 |
| CloudBrowser | 云端文件列表（表格/网格），文件下载触发，排序与筛选 |
| WatchSourcePanel | 监听源列表管理，添加/移除/状态显示 |
| SettingsPage | 网盘授权管理、云端根目录配置、通知策略、过滤规则、开机自启 |
| ConflictDialog | 冲突弹窗模态框，三项选择（保留本地/保留云端/保留两份） |

### 数据模型

```
ICloudAdapter 接口:
  upload(localPath, remotePath, onProgress) → Promise<Result>
  download(remotePath, localPath, onProgress) → Promise<Result>
  listFiles(remoteDir) → Promise<FileInfo[]>
  deleteFile(remotePath) → Promise<Result>
  getFileInfo(remotePath) → Promise<FileInfo>
  getQuota() → Promise<QuotaInfo>

TransferTask:
  id, localPath, remotePath, direction(upload|download),
  status(pending|transferring|paused|completed|failed),
  progress(0-100), speed, eta, retryCount, createdAt

FileInfo:
  name, path, size, mtime, isDir

WatchSource:
  id, localPath, remoteDir, status(active|error|paused),
  filterRules[]

AppConfig:
  baiduOAuthToken, remoteRootPath("/我的同步文件/"),
  notificationLevel("all"|"error_only"|"off"),
  theme("light"|"dark"|"system"), autoLaunch(bool),
  filterRules[{pattern, type}]
```

### 核心交互细节

- **拖拽区域**: 未授权时显示"请先授权百度网盘"引导；已授权时显示拖拽提示"拖拽文件到此处上传"，有视觉高亮反馈。
- **进度展示**: 每个任务独立行，显示文件名、进度条、百分比、速度（MB/s）、预估剩余时间。状态颜色：进行中=蓝色，完成=绿色，失败=红色，暂停=灰色。
- **冲突弹窗**: 模态弹窗，展示本地和云端文件的名称、大小、修改时间对比，三个操作按钮对应三种选择。
- **托盘图标**: 同步中=动态旋转动画，空闲=静态图标，错误=红色感叹角标。
- **窗口关闭**: 点击 X → 最小化到托盘 + 显示提示"应用已最小化到系统托盘"。右键托盘图标 → 退出 → 彻底关闭。
- **云端浏览**: 表格列 = 文件名 + 大小 + 修改时间；每行有下载按钮；点击下载 → 弹出保存路径选择对话框 → 加入传输队列。

## 测试决策

### 测试策略
- 使用 Vitest 作为测试框架
- 测试外部行为，不测试实现细节
- 模块间通过接口隔离，mock 外部依赖（百度网盘 API、文件系统）

### 测试范围

| 模块 | 测试内容 |
|------|---------|
| TransferQueue | 添加任务、并发控制（最多 3 个同时进行）、暂停/恢复/取消、重试逻辑（3 次指数退避）、队列持久化与恢复 |
| ConflictDetector | 无冲突场景（云端更旧/不存在）、冲突场景（云端更新）、边界情况（文件不存在） |
| FilterManager | 精确匹配、通配符匹配、排除规则增删 |
| CloudAdapter (Baidu) | 接口契约测试：上传/下载/列表/删除/文件信息/配额查询的参数验证和返回格式 |
| SyncEngine | 拖拽触发上传链路、监听变更触发上传链路、冲突拦截流程 |

### 不测试的内容
- chokidar 行为（第三方库，由库自身保证）
- Electron 原生 API（托盘、通知、开机自启由集成测试或手动验证）
- React 组件渲染细节（UI 交互由手动验证或 E2E 测试覆盖）

## 不在范围内（v1）

- 双向同步（仅单向备份：本地→云端）
- 云端文件版本历史管理
- 多网盘同时接入（架构预留适配器接口，首期仅百度网盘）
- 文件分享链接生成
- 带宽限速
- 定时同步
- 多用户 / 团队协作
- macOS 签名公证（首期聚焦 Windows）
- 大文件分片上传（单文件 >1GB 场景后续实测后按需引入）

## 补充说明

- 百度网盘 Open API 的可用性和限流策略不在控制范围内，需关注官方 API 变更公告。
- 适配器架构参考 Rclone 的设计理念，确保后续接入其他云盘时代码改动最小。
- 首期打包格式为 Windows NSIS 安装包（.exe）。
