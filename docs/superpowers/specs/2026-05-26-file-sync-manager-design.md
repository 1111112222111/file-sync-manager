# 文件自动同步管理器 — 设计规格

## 概述

基于 Electron 的桌面端文件自动同步工具，绑定百度网盘实现文件云端同步。支持拖拽上传、文件监听自动同步、云端文件浏览下载，后续可扩展接入更多云盘。

## 决策记录

| # | 决策项 | 选择 |
|---|--------|------|
| 1 | 技术平台 | Electron + React |
| 2 | 网盘范围 | 百度网盘 + 适配器接口（后续可扩展阿里云盘等） |
| 3 | 版本管理 | 简单覆盖，上传新版本直接替换云端文件 |
| 4 | 同步范围 | 默认同步工作区（拖拽即上传）+ 可注册任意文件夹为监听源 |
| 5 | 冲突处理 | 弹窗询问用户选择覆盖方向或保留两份 |
| 6 | 文件过滤 | 默认全量同步，用户可手动添加排除规则（文件/文件夹） |
| 7 | 后台运行 | 主窗口 + 系统托盘，关闭窗口最小化至托盘，可选开机自启 |
| 8 | 同步方向 | 单向备份：本地为主版本，上传至云端；下载为手动操作 |
| 9 | 视觉风格 | 深色 / 浅色主题可切换 |

## 模块设计

### 1. 传输队列管理器 (TransferQueue)

**职责**：管理所有上传/下载任务，控制并发、处理重试、推送进度。

- 最大并发上传数：3（可配置）
- 失败自动重试：最多 3 次，指数退避
- 进度回调：每 100ms 推送一次进度更新到渲染进程
- 队列持久化：应用退出时保存未完成任务，启动后恢复

**接口**：
- `addTask(filePath, direction)` — 添加传输任务
- `pauseTask(taskId)` / `resumeTask(taskId)` — 暂停/恢复
- `cancelTask(taskId)` — 取消任务
- `getQueueStatus()` — 获取队列状态

### 2. 文件监听器 (FileWatcher)

**职责**：基于 chokidar 监听注册的文件/文件夹，检测变更后触发自动上传。

- 防抖延迟：300ms（合并短时间内多次变更）
- 忽略规则：遵循过滤管理器配置的排除列表
- 事件类型：add / change / unlink
- 变更文件加入传输队列自动上传

### 3. 云盘适配器 (CloudAdapter)

**职责**：统一云盘操作接口，隔离各云盘 API 差异。

**ICloudAdapter 接口定义**：
```
upload(localPath, remotePath, onProgress) → Promise<Result>
download(remotePath, localPath, onProgress) → Promise<Result>
listFiles(remoteDir) → Promise<FileInfo[]>
deleteFile(remotePath) → Promise<Result>
getFileInfo(remotePath) → Promise<FileInfo>
getQuota() → Promise<QuotaInfo>
```

**百度网盘适配器**：基于百度网盘 Open API 实现上述接口。使用 OAuth 2.0 授权，Token 本地加密存储，自动刷新。

### 4. 冲突检测器 (ConflictDetector)

**职责**：上传前检查云端文件是否比本地版本更新，触发冲突处理。

- 比较本地文件修改时间与云端文件最后修改时间
- 触发条件：本地和云端都有修改，且云端版本更新
- 弹窗选项：
  - 保留本地版本（上传覆盖云端）
  - 保留云端版本（跳过本次上传）
  - 保留两份（云端重命名为 `filename_conflict_日期`，然后上传本地版本）

### 5. 过滤管理器 (FilterManager)

**职责**：维护文件/文件夹排除规则列表。

- 默认规则：无（全量同步）
- 用户可通过设置页添加排除项
- 支持精确匹配和通配符匹配
- 排除项持久化存储

### 6. 托盘管理器 (TrayManager)

**职责**：管理系统托盘图标、菜单和桌面通知。

- 托盘菜单项：打开主窗口 / 暂停同步 / 最近传输 / 设置 / 退出
- 桌面通知：上传完成 / 下载完成 / 冲突 / 错误
- 窗口关闭行为：最小化到托盘（非退出）
- 开机自启：通过 auto-launch 实现，设置页开关控制

## 数据流

### 上传流程
```
用户拖拽/文件变更 → UI 显示任务 → 传输队列排队
→ 冲突检测（如有冲突弹窗询问）
→ 适配器.upload() → 进度回调更新UI
→ 完成 → 通知 + 更新同步状态
```

### 文件监听流程
```
chokidar 检测变更 → 过滤管理器检查 →
防抖 300ms → 加入传输队列 → 自动上传
```

### 云端浏览下载
```
用户点击"云端文件" → 适配器.listFiles()
→ UI 展示列表 → 用户选择文件 → 适配器.download()
→ 进度展示 → 保存到本地工作区
```

## 技术选型

| 类别 | 选择 | 说明 |
|------|------|------|
| 框架 | Electron | 跨平台桌面应用 |
| 前端 | React + TypeScript | UI 构建 |
| 构建 | Vite + electron-builder | 开发与打包 |
| UI 组件 | 自定义 + CSS Variables | 深浅主题切换 |
| 文件监听 | chokidar | Node.js 最成熟的文件监听库 |
| 本地存储 | electron-store (JSON) + better-sqlite3 | 配置 / 传输记录 |
| 开机自启 | electron-auto-launch | 跨平台自启 |
| 网盘SDK | 百度网盘 Open API (RESTful) | OAuth 2.0 |
| 打包 | electron-builder | Windows NSIS 安装包 |

## 非功能需求

- **性能**：上传/下载不应阻塞 UI，所有传输在主进程中异步执行
- **可靠性**：网络中断后自动重试，应用崩溃后队列可恢复
- **安全性**：网盘 Token 使用安全存储（electron-store 加密），不外泄
- **可用性**：拖拽区域醒目，进度实时可见，操作反馈及时

## 暂不纳入一期

- 多网盘同时支持（架构预留，首期仅百度网盘）
- 文件分享链接生成
- 带宽限速
- 定时同步
- 云端版本历史管理
